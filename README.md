# Background
In this project, we will be building Machine Learning algorithms from scratch using only numpy. Our purpose here is to review math behind main algortihms and implement it. In real world, we almost never have to build models from ground up but it is a good exercise to have a hands-on experience in inner workings of those models.

# Scope
We will review necessary mathematical bacgrounds for an algorithm and then implement it in code.
We will not analyze data - data we use will mostly be toy data created semi-randomly
We will not discuss the code in detail - while we will mention the intent of code lines when necessary, we will not spend majority of our time discussing the code

# Struture
Most/All of our codes will live in notebooks. While not practical in production, it will allow us discuss the implementation in detail.
We will start easy with Simple Linear Regression and then build up to Multiple Linear Regression. Later on, we will be looking at different algorthims (TBD)
